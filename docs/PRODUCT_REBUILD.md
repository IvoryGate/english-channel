## 工程结构的取舍

保留一套频道控制层、三个生产适配器、provider 与音频溯源。暂不重写前后端，
不另建调度器，不再发展并列运营数据库。channel_ops 和 JSON 账本是有来源的
迁移输入，先证明身份一致，再切换权威来源。素材存在性、引用和指纹进入验收。

每个切片交付一项真实行为、对应测试和文档，明确“已实现、已验证、待实验、
受阻”。每次交接读取本文件、当前切片计划和 readiness 输出；历史计划是证据库，
不是互相竞争的今日指令。运行：

```powershell
.\.conda-env\python.exe scripts/channel.py readiness --as-of 2026-11-06T12:00:00+08:00
```

参见 [CHANNEL_READINESS.md](CHANNEL_READINESS.md)。这个诊断不初始化数据库，
不授予发布权限，也不能证明声音悦耳或选题有市场。

## 音频质量

见 [AUDIO_QUALITY_RESET.md](AUDIO_QUALITY_RESET.md) 和
[`audio-audition-v1.json`](../configs/quality/audio-audition-v1.json)。先比较同文本、
音色与 seed 的单变量表现力参数，再独立检查后期。角色需要目的、误解、回应和
情绪变化；母带处理无法把说明书式对话变成可信互动。模型不支持的指令标为编辑
意图，不能声称已经执行。

首次审核约 12 分钟，通过后再做 8–12 分钟疲劳测试。正式生产保留模型、音色、
文本、参数、seed 与输出指纹。改参必须正确使缓存失效。停顿、字幕和章节共用
实测时间轴是独立切片，不能只改其中一项。

## 定位、视觉与社区

见 [MARKET_AND_CREATIVE_RESET.md](MARKET_AND_CREATIVE_RESET.md) 和
[`creative-brief-v1.json`](../configs/quality/creative-brief-v1.json)。零付费下优先
研究现有频道和可公开验证的需求。实用英语是候选，不能因工程投入就默认胜出。

每期把标题承诺、开场内容、图片冲突、练习和社区回访对应起来。提示词写人物
行为与构图，固定角色、布局和参考版本，一次比较一个实质差异。正文图与封面
分开设计；生成次数有上限，失败有原因，接受资产保留提示词与哈希。

社区延续一次学习体验：看片后回答一句话 → 次日解释常见错误 → 下一期采用
真实反馈。频道自发示范不算观众反馈；用独立参与者、有效回答、未答问题和采用
记录衡量，不用发帖数量冒充关系质量。

## 指标与经营模式

先以免费内容验证价值，不提前建设会员站、课程商城或多平台工程。后续收入可
评估平台广告、原创练习材料、深度产品，但前提是有真实需求和成本证据；没有
新增付费或商业设置变更授权。

- 包装：按来源/观察窗口比较曝光、点击、每千次曝光观看分钟；低曝光不硬判胜。
- 内容：30 秒留存、练习段掉点、观看比例、错词与疲劳感。
- 关系：返回观众、独立参与者、连续练习；四周不能证明长期忠诚。
- 效率：每合格成品分钟的总耗时、人工分钟、失败、峰值资源、返工率。
- 业务：真实订阅转化、成本与收入；缺失不填零。

实验事先记录假设、主指标、对照、干扰因素、最低证据和停止规则。跨视频匹配
比较属于观察，不冒充随机实验。竞品规模不能转化为本频道增长保证。

## 自治边界与人工投入

目标循环：证据更新 → 提案 → 预算内制作 → 质量检查 → 按有效策略发布 →
到期测量 → 决策。自动生成文件不等于闭环存在。

每周默认 45 分钟：10 分钟事实/异常，12 分钟盲听，8 分钟封面和开场，10 分钟
反馈与实验决定，5 分钟必要审批。Agent 可独立研究、整理、测试与本地准备；
发布和社区回复需要有效动作范围与远端核验。无变化的成功不反复打扰，重大
品牌/公开格式/付费决定形成具体可审查方案。不得无限重试绕过暂停和异常。
