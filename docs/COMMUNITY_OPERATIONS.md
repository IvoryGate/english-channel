# Community Operations

## Cadence

Owner approved 2026-10-18: one Community post daily (seven weekly), one useful
channel comment on every new video, and continuous historical backfill in each
video's comment section. The owner removed the daily ten-video limit on
2026-10-18. Use Asia/Shanghai throughout. Default post time: 12:00; schedule a
seven-day buffer when available. Do not add a second post just to catch up.

Rotate topic polls, listening-detail questions, one-sentence reply practice,
natural-expression choices, practical scenarios, reading discussion, and
weekly feedback. Each post contains one answerable task. Match content to
published videos; avoid advertising-only posts or unsupported learning claims.

## Per-Video Interaction

Inspect title, description and local script/subtitles before drafting. Long
videos receive a relevant practice question; Classics a chapter-specific
discussion question; Shorts a short choice or one-line response exercise.
For a quiz, include the answer and brief explanation after a clearly labelled
separator, or in the channel's reply. Open questions may include an example.
Never pretend a channel-authored example came from a viewer.

Check existing channel comments first. Reuse a suitable existing interaction;
do not duplicate it. Pin when supported and no suitable pinned comment would
be displaced. A published video is operationally incomplete until its comment
is verified, or a real platform limitation is recorded. Scheduled/private
videos receive their comment only when comments become available.

## Daily Work And Evidence

Prioritize new public videos, substantive unanswered viewer comments, then
historical backfill: newest fortnight, older videos still receiving traffic,
remaining catalogue. Proceed sequentially without an artificial daily count
limit; count only successful, verified writes. Pause writes on an actual
platform restriction and record the exact boundary. Do not evade rate limits.

Record video/post ID, exact text, remote URL, status, pin state, and check time
in `workspace/community/`. Pending, attempted, published, scheduled and
blocked are distinct states. Keep a single browser tab and bounded output.
Review substantive replies within 24 hours when the signed-in browser works;
report any access blocker instead of promising unattended replies.

## Weekly Completion

Weekly video planning must include seven Community posts, a per-video comment
checklist, remaining historical backlog, due replies, and an audience-feedback
summary. Video upload completion alone does not close channel operations.
Review votes, substantive comments, recurring questions and any observable
return visits weekly. Feed findings into the established delayed video-review
cycle. Do not infer causation or set success claims from tiny samples.
