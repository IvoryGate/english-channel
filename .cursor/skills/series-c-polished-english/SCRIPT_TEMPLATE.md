# Series C — Polished English Script Template

Use this structure for every Series C episode. Frozen sections are marked **[FROZEN]**.

## Header (metadata block)

```
Title: [Concrete situation + outcome/paradox | Polished English Podcast B2-C1]
Description: [One sentence learner problem + promise]
Target Level: B2-C1
Estimated Duration: 16-20 minutes
Hosts: Leo, Mia
Show Profile: series_c
Archetype: A (narrative) / B (checklist) / C (topic-deep)
Learner Problem: [One sentence]
Key Phrases: [3-5 phrases, comma-separated]

characterProfiles:
  Leo: "Leo, facilitator, warm precise, consistent manner"
  Mia: "Mia, listener voice, warm slightly self-aware, consistent manner"
```

## Structure map (include in draft)

| Phase | Time band | Focus | Spoken transition style |
|---|---|---|---|
| 起 | 0–~4 min | Thesis-first hook + early contract | Hook → story → "we'll replay a few phrases at the end" |
| 承 | ~4–~12 min | 2–3 threads, question-flow | "Here's where people mess up first —" / "Next friction —" |
| 转 | ~12–~16 min | Pattern interrupt + Mia pushback + conflict recycle | "But here's the thing —" / Mia: "I won't do a spreadsheet week." |
| 合 | ~16–20 min | Honest payoff + word tour + close | "Four phrases we kept using + the [X] we demonstrated" |

## Body

### [Intro Hook]  — 起 (20%)

**[FROZEN cold open]**

```
[Music sting]
Leo:  Hey. Welcome back to Polished English, the show where two people talk
      about real life, and you overhear the English you actually need.
Mia:  I'm Mia.
Leo:  And I'm Leo. And this is the English Listening Room.
```

**[Hook — pick one template from STYLE.md §C.2]**

```
[Delivery: quiet conviction, thesis-first]
Leo:  [Thesis line — paradox / pain / promise, 1-2 sharp sentences]

[Delivery: listener recognition, slight laugh]
Mia:  [Reaction — "Oh, that hits." / "Tell me about it." / short story beat]
```

**[Early contract (P0) — one line promising slow end recap]**

```
[Delivery: friend-to-friend, casual]
Leo:  And stick around — at the end we'll replay a few phrases slowly, so you can pocket them.
```

**[Level callout]**

```
Mia:  If you're B2 or C1, this one's for you.
```

### [Body]  — 承 (40%)

2–3 threads. Each thread follows this micro-structure:

```
[Delivery: listener voice, story]
Mia:  [Story / scene / opinion — 2-3 sentences]

[Delivery: facilitator tightening, conversational]
Leo:  [Short tighten — name the pattern or phrase, 1-2 sentences]

[Delivery: applying to self, half-joking]
Mia:  [Mirror / apply to self / pushback — 1-2 sentences]

[Delivery: warm affirmation]
Leo:  [Affirm + handoff — "Right." / "Exactly." / "That's the move."]
```

Example thread (fill in real content):

```
[Delivery: listener voice, slightly self-conscious]
Mia:  So I rewrote that email four times. Same email. Four times. At 11pm.

[Delivery: facilitator, leaning in]
Leo:  Right. And the thing you kept changing was the claim — how strong it sounded.

[Delivery: recognition, half-laugh]
Mia:  Yeah. I kept softening it. "I think," "maybe," "just wanted to check." Until it said almost nothing.

[Delivery: quiet conviction]
Leo:  That's the move most people miss. Softening a claim is a skill — but over-softening erases you.
```

Repeat for 2–3 threads. Use **question-flow** transitions between threads:
- "Here's where people mess up first —"
- "Next friction —"
- "Last head-trip to name —"
- "There's a reason your brain checks out —"

**[Optional micro-pocket after first thread — ~20–45s]**

```
[Delivery: slowing down, friend-to-friend]
Leo:  Tiny pause. Two phrases from that last piece: "circle back" and "soften the claim." Pocket those. Back to the chat.
```

### [Pattern Interrupt + Conflict Recycle]  — 转 (25%)

**[Pattern interrupt]**

```
[Delivery: pattern interrupt, direct]
Leo:  But here's the thing. If you understand 100% of this show every time, you might be coasting. And coasting is its own problem.
```

**[Mia pushback]**

```
[Delivery: listener pushback, half-joking but real]
Mia:  Okay, but tomorrow is insane. I'm not doing a spreadsheet week. I'm not setting a timer for every email.
```

**[Conflict recycle — negotiate tiny real step]**

```
[Delivery: facilitator, practical]
Leo:  Right. So don't. Pick one email tomorrow. One. Before you send, read the first line aloud. If it sounds like a brush-off, rewrite it once.

[Delivery: reluctant but willing]
Mia:  One email. One read-aloud. Fine. I can do that.
```

### [Word Tour + Close]  — 合 (15%)

**[Honest stay payoff line — concrete payoff of listening to end]**

```
[Delivery: warm, steady]
Leo:  So if you stayed this long: four phrases we kept using today, plus the one-read-aloud move we just demonstrated. Here they are, slowly.
```

**[Word tour — 2–4 items, all pre-heard]**

For each item:

```
[Delivery: slow, clear]
Leo:  [Phrase]. [English gloss — one sentence]. Like when [brief example].
Mia:  [Phrase] — got it.
Leo:  Nice.
```

**Mirror echo rule (TTS):** avoid bare one-word turns (`Hook.` / `Tangent.` alone). VoxCPM often hallucinates 5–9s on single-word mirrors and fails QC. Use a 2–4 word echo (`Hook — got it.`, `Lose the table.`) or repeat the phrase in a short sentence.

**[Short close + optional light CTA]**

```
[Delivery: warm landing]
Mia:  That's it for today. One email. One read-aloud. See you next time.

[Delivery: occasional light CTA, not hype]
Leo:  And if this helped, follow the show — it helps us keep making them.
```

**[FROZEN sign-off]**

```
Mia:  This is Mia.
Leo:  And this is Leo.
Mia:  And you've been listening to Polished English, from the English Listening Room.
Leo:  Bye.
[Music sting]
```

## Studio JSON handoff (optional, after approval)

When converting to `script.json` for the manifest, each turn object:

| Field | Rule |
|---|---|
| `id` | Stable slug, unique |
| `speaker` | `alex` (Leo's audio via `participants`) or `sarah` (Mia's audio) — lowercase keys |
| `text` | English line; on-mic names Leo/Mia in prose; no bracket stage directions unless pipeline supports |
| `deliveryCue` | Natural-language performance phrase (mirrors `[Delivery: …]` from markdown) |
| `emotion` | Optional one-word summary for QC tooling; NOT a prosody lever for clones |
| `pause_after` | Seconds of silence after this segment; longer on final segment for outro tail |
| `speed` | Must be `1.0` on every segment |
